Latin America Conflict & Cartel Violence Dashboard

An interactive Power BI dashboard analyzing ACLED conflict event data across 17 selected Latin American countries from 2019 through 2024. The report tracks 146,038 events and 129,504 fatalities, with filters for country, event type, actor, and date. It is designed to support regional security analysis by showing where violence is concentrated, which actors are associated with the most fatalities, and how conflict patterns have shifted over time.

Key Findings

  • The dashboard covers 146,038 ACLED events and 129,504 reported fatalities across 17 selected Latin American countries from 2019 to 2024.
  • Mexico is the deadliest country in the dataset, with 48,945 fatalities, while Brazil records the highest event volume, with 55,030 documented events.
  • Violence against civilians is the largest event category by both volume and lethality, accounting for 80,483 events and 86,475 fatalities.
  • Battles account for 43,112 events and 42,464 fatalities, making them the second-largest violence category and a major driver of regional fatality totals.
  • Regional event volume peaked in 2023 at 26,049 events, with 2024 remaining elevated at 25,505 events rather than returning to pre-2022 levels.
  • The actor-level views show that unidentified gangs and armed groups in Mexico, Brazil, Colombia, Ecuador, and Honduras dominate the highest-fatality actor categories.

Data Source

Data sourced from the Armed Conflict Location & Event Data Project (ACLED) via the ACLED Data Export Tool. ACLED collects real-time data on the locations, dates, actors, fatalities, and types of political violence and protest events across the world. For more information, visit acleddata.com.

Citation: ACLED. (2026). Armed Conflict Location & Event Data Project. Retrieved via the ACLED Data Export Tool from https://acleddata.com.
